# 快速上手

从 SD 卡到一台为孩子设置好的主机，大约十分钟，然后是日常操作。返回 [README](../../README.md)。

## 开始之前

- **一台运行 Atmosphère 的主机。** PlayGuard 通过一个受限的服务操作主机自身的家长控制：它需要自制固件。主机没有破解？那它帮不上忙（[故障排除](troubleshooting.md#主机未破解)）。
- **受支持的系统版本。** 21.0.0 到 23.0.1 可以使用所有功能；更早的版本，除游戏时间计时器外都可用；更新的版本会以只读方式打开，直到有发布版本支持它（[兼容性](compatibility.md)）。
- **整台主机一个限制。** 游戏时间计时器是主机的：对所有用户都一样。想给每个孩子设置不同的限制，需要另一种工具（[原因](compatibility.md#playguard-还是替代型-sysmodule)）。

想先看看？[在浏览器中试用 PlayGuard](https://guard.boreale.dev/simulator/?not_set_up=1)，对着一台首次启动的模拟主机。

## 1. 安装

在 Homebrew App Store 或 sphaira 的 App Store 中搜索 *PlayGuard* 并安装。也可以手动安装：从[最新版本](https://github.com/JigSawFr/PlayGuard/releases/latest)下载 `playguard.zip`，解压到 SD 卡的根目录（[安装](install.md)）。

> [!TIP]
> 同时解压 `playguard-rescue.zip`，即可选的恢复 sysmodule。在你需要它之前，它什么也不做；如果 0 分钟的限制阻止了一切而 PIN 又忘记了，它是唯一的回退办法（[被锁在外面？](troubleshooting.md#被锁在外面)）。

## 2. 以正确的方式打开

**在游戏之上**（启动游戏时按住 R，使用 hbmenu、sphaira 或 Homebrew App Store）、用**家长的用户**打开 PlayGuard：

- 在游戏之上，PlayGuard 作为应用运行，可以使用全部内存；从相册打开时，它作为小程序运行，内存较少；
- 这段时间算作孩子的游戏时间，除非开启了 *安全 › 我在PlayGuard中时暂停家长控制*（默认关闭）：开启后，输入 PIN 后在你使用 PlayGuard 期间，它会暂停家长控制；你离开时，家长控制会重新开启。
- 输入 PIN 后，在你使用 PlayGuard 期间，它会暂停家长控制，这段时间就不会占用孩子的时间；你离开时，家长控制会重新开启。

## 3. 按照 *入门* 操作

首次启动时，会出现 *入门* 向导（之后可以在 *偏好设置 › 入门* 中打开）。在完成之前，*今天* 会以一张卡片显示同样的步骤（*1 / 3*）：

1. **PIN。** 主机自身的 PIN，HOME 菜单在超过限制后启动游戏或更改设置时会要求输入。避免使用 0000、1234 或 2580：PlayGuard 会标出任何人都会先试的 PIN。
2. **每日限制。** 每天相同，或者工作日一个、周末一个。之后可以在 *游戏时间* 中单独更改任何一天。
3. **网络时钟。** 游戏时间计时器依靠它计时。从不连接任天堂服务器的主机，这个时钟会一直不准：见第 5 步。

## 4. 解除手机应用的关联

仍然关联着任天堂的 *家长控制* 应用（或者二手主机关联着别人的应用）？*安全 › 解除手机应用的关联*。否则，应用下次同步会覆盖你在 PlayGuard 中设置的内容。它可以离线使用。

## 5. 设置网络时钟

*主机 › 网络时钟 › 测量时间差* 会询问三台公共时间服务器，然后选择 *设置网络时钟*。设置时钟会让今天的游戏时间重新计算，所以请在孩子玩之前完成。

没有联网的主机：没有服务器回应时，PlayGuard 会提议改为把网络时钟设为主机时钟。请先用手机或手表核对主机时钟，同时让 *系统设置 › 主机 › 日期和时间 › 通过互联网同步时钟* 保持关闭（[详情](features.md#网络时钟)）。

## 6. 选择时间到时会发生什么

*游戏时间 › 时间到时*：主机显示“时间到”，然后**中断游戏**或**只作提醒**。中断可以不用争吵就让游戏停下来，但未保存的进度可能丢失；只作提醒则交给孩子自己决定。如果需要，可以在同一个标签页上添加**就寝提醒**。

## 7. 保护 PlayGuard 本身

*安全 › 用PIN保护PlayGuard*：

- **更改前**（默认）——任何人都可以查看，只有家长能更改；
- **打开PlayGuard时**——启动时显示锁定画面；
- **从不**——设置了 PIN 时，PlayGuard 会在铃铛中标出这一点。

## 8. 把主机交给孩子

*今天 › 给孩子看* 只显示剩余时间和游戏何时结束，字大到在房间另一头也能看清。按 Ⓐ 并输入 PIN 会回到家长的画面。

> [!IMPORTANT]
> **在 HOME 菜单中留着没关的游戏会继续计时。** 关闭它，或让主机进入睡眠模式（[什么算作游戏时间](features.md#什么算作游戏时间)）。

## 日常操作

| 想要… | 在哪里 |
|---|---|
| 今天多给一些时间 | *今天 › 加时*（+15 分钟、+30 分钟、+1 小时）。第二天会自动恢复。 |
| 在其他日子多给一些时间 | *今天 › 加时 › 其他日子…* |
| 今天到此为止 | *今天 › 今天到此为止*：现在，或者 5 分钟后，留出存档的时间。 |
| 更改某一天的限制 | *游戏时间*：在那一天上按 Ⓐ，↑/↓，然后按 **+** 保存。 |
| 在上学期间和假期之间切换 | *游戏时间 › 配置*。 |
| 查看谁玩了什么 | *游玩记录*：按游戏、按用户，今天、7 天、累计；导出。 |
| 暂时阻止所有游戏 | *游戏时间 › 阻止所有游戏*。关闭后会恢复之前的限制。 |
| 撤销一项更改 | 更改后立即按 **ZR** *撤销*，或者随时在 *历史记录 › 通过PlayGuard进行的更改* 中撤销。 |
| 保存一份设置副本 | *历史记录 › 备份设置*（从不包含 PIN）。 |
| 了解需要你处理的事情 | 铃铛（Ⓨ）：需要处理的以琥珀色显示，需要了解的带一个“i”。 |
