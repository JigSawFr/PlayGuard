## 操作

| 按钮 | 作用 |
|---|---|
| ↑/↓ | 移动 |
| Ⓐ | 确认 |
| Ⓑ | 返回或取消（在侧边栏按两次退出） |
| Ⓧ | 刷新（在读取主机的标签页上） |
| Ⓨ | 通知，在任何标签页都可用 |
| **−** | 语言和主题，在任何标签页都可用（底栏不显示它们，由标题栏的铃铛、语言和主题显示） |
| **+** | 保存按天设置的限制（以及在 *游戏时间* 中修改的一周） |
| **ZR** | *撤销*，在保存一项更改后的几秒钟内可用 |

应用按标签页组织，和主机的“设置”一样；每个标签页在下面都有一节说明。

- **失败的操作会在对话框中说明，成功的操作以提示消息显示。** 对话框只说明此时适用于这台主机的情况：只有在有游戏打开时，才会提到正在进行的游戏会被中断；只有在手机应用已关联并且能够同步时，才会提到它可能覆盖更改。
- **标题栏**：家长控制暂时解除期间，会在每个标签页上说明这一点（它的胶囊标签）；应用处于只读模式时，标题右侧会显示一支划掉的铅笔；点击其中任何一个都会前往撤销的地方（*PIN › 重新启用家长控制*、系统版本画面）。
- **在只读模式下**，操作仍留在原处，显示为灰色，按下时会说明原因。

## 外观：Cadran

PlayGuard 的外观名为 Cadran：标签页使用图标侧栏，配色为海军蓝或冷白色（随主题而定），用卡片代替列表。每个标签页一打开就显示最重要的内容（圆环、方块、卡片、标签按钮），其他设置放在下方。

- **标题栏的胶囊标签**说明这个标签页的主题（*家长控制已开启*、*计时中*…）；家长控制解除期间，它会在每个标签页上说明这一点，点击它会打开 *PIN › 重新启用家长控制*。次要文字从不小于 15 px，坐在沙发上看电视也能看清。
- **对话框**是卡片，按钮为胶囊形，确认按钮为青绿色（删除或停止某项内容时为珊瑚色）。
  - 选项以卡片形式在操作提示上方展开，当前选项为浅青绿色底并带勾号。青绿色边框在任何地方都只属于焦点：等级、用户、正在生效的选项都保留浅色底。
  - 较长的对话框在后面还有内容时底部会渐隐，其中的警告（游戏即将被中断）放在最前面，显示在琥珀色卡片中。
  - 操作失败时，标题说明是什么失败了，错误代码以小字显示在原因下方，有帮助时还会提供 *发送报告*。
  - 消息以卡片形式出现在标题栏下方，已完成的操作带青绿色勾号，被拒绝的操作带琥珀色标记。
- **其他画面**也采用同样的外观：配置的按天编辑器像 *游戏时间* 一样显示一周（修改方式相同，快捷填充以方块显示）；*检查已安装的游戏* 和 *所有游戏* 把每一行放进卡片；*配置* 和 *帮助与诊断* 为每一行配上图标。
- **文字大小**（*偏好设置*，或标题栏中的 **AA**）：
  - *自动*（默认）在主机插在底座上、显示在电视上时把所有文字放大 25%，回到掌机模式时恢复原样；*较大* 始终放大，*标准* 从不放大。
  - 标题栏、侧边栏和底栏保持原来的大小（没有更多空间），“限制”中各等级的名称也一样（本来就够大）。
  - 更改立即在所有画面上生效，无需重启。
  - 25% 这个数字来自一台 55 英寸的 4K 电视：此时最小的文字（15 px）大写字母高 14.6 毫米，从 2.5 米外看为 20′ 视角，阅读起来很舒适（标准大小时为 16′，是最低限度）。
- **视觉效果**（*偏好设置*）：*电池供电时精简*（默认）在没有连接充电器时（掌机模式、未插电）省去背景光晕、儿童画面圆环在最后几分钟的跳动，以及圆弧滑向新数值的动画；*始终完整* 则保留它们。每 5 秒重新检测一次，所以给主机接上电源后，这些效果就会回来。
- **撤销：** 保存一项更改后，**ZR** *撤销* 会在底栏中停留几秒钟：它会在更改历史中打开这项更改，以便恢复之前的值。更改历史为空时，会用一张卡片说明。

## 通知——在任何标签页都能看到需要你处理的事情

标题栏中版本号左侧的铃铛汇总需要家长处理的事情；在任何标签页按 Ⓨ 都能打开列表（有两件事待处理时，铃铛的角标显示 *2*）。

铃铛左侧是语言（它的代码，*FR*、*EN*…）和主题（太阳表示浅色，月亮表示深色，半满的圆表示跟随主机），然后是文字大小（**AA**，文字放大时其中的大 A 显示为青绿色）：点击会打开与 *偏好设置* 中相同的列表，在任何标签页按 **−** 也能选择它们。新的主题或语言会立即生效，各个画面在同一标签页上重新生成，焦点仍在同一行，中文及其专用字体也是如此。

### 待处理

每项都带琥珀色警告标志，以琥珀色计入铃铛上的数字；它会一直保留到问题解决：

- 还没有 PIN，或者是任何人都会先试的 PIN（0000、1234、1212、2580…：在主机上判断，从不显示）；
- 主机上有 PIN，但 PlayGuard 本身打开时不需要它（*用PIN保护PlayGuard* 设为 *从不*）；
- 家长控制已暂时解除（*重新启用*）；
- 之前某天的加时还需恢复；
- “时间到”提醒已关闭；
- 在 PlayGuard 之外所做的更改；
- 主机没有计算游戏时间；
- 网络时钟不准确。

### 仅供参考

每项都带一个“i”，铃铛上显示一个圆点；可以标记为已读：

- 之前某天被 *今天停止游玩* 降低的限制仍未恢复（*恢复*）；
- 安装了新版本（*新功能*；原地更新后，保留了之前的构建），或者 PlayGuard 有新版本；
- 在线发送了报告（*显示链接*），或者 PlayGuard 上次意外关闭（*发送报告*）；
- 本周的游戏时间（每 7 天一次，直到已读；并按天与前一周比较；*显示二维码* 会在 *游玩记录* 中打开本周摘要），以及在主机只提醒的情况下，最近 7 天中有两天或以上超过了限制；
- 需要备份设置（还没有备份，或 30 天没有备份）；
- 所有游戏已被阻止一周；
- 新的用户账户；
- 手机应用已关联；
- 启动时发现网络时钟有偏差。

### 主机

与主机本身而不是家长控制有关的条目排在最后，合并为一行，按 Ⓐ 展开（没有其他条目时直接展开）。其中待处理的条目计入“主机”标签页的标记，而不是铃铛：

- 已安装的游戏无法启动（*检查已安装的游戏*），游戏补丁需要查看；
- SD 卡空间快满（少于 500 MB）；
- PlayGuard 自己的某个文件无法移到一旁或无法写入 SD 卡；
- 恢复 sysmodule 不是最新版本（不是这个版本附带的那个，或者安装于它记录版本号之前；*更新* 会装上这个版本附带的那个），之后需要重启主机才能生效，直到重启为止；
- 某个构建未能完成启动，已退回（*发送报告*）。

仅供参考的条目：已退回之前的构建；系统版本未用这个版本测试过；Atmosphère、hekate 或系统版本有新版本（通过 *每天检查更新* 检查；系统版本的条目会建议等到 Atmosphère 支持它）；emuMMC 上的序列号未隐藏；另一个系统有自己的家长控制；PlayGuard 自己的某个文件被发现损坏并已移到一旁（启动时会有一条提示消息指向它）。

### 条目如何运作

- 每一节的条目按固定顺序排列，与哪项检查先完成无关。
- **在侧边栏中**，标签页名称旁的琥珀色标记统计该标签页中待处理的条目，也就是能解决它们的地方：PIN 标签页（没有 PIN、PIN 太简单、PlayGuard 未用 PIN 保护、已暂时解除）、游戏时间（提醒已关闭、主机没有计时）、*今天*（在 PlayGuard 之外所做的更改、需要恢复的加时）、主机（上面所说的条目，以及网络时钟）。已忽略的条目和仅供参考的条目不计入。
- 在标签页中，同样的标记显示在解决每个问题的那一行上（*网络时钟*、*检查已安装的游戏*、*存储*、*游戏补丁*；*设置或更改PIN*、*用PIN保护PlayGuard*、*重新启用家长控制*；提醒对应游戏时间的 *高级*），标签页会打开到其中第一项。
- 在条目上按 **Ⓐ** 会直接解决（*打开*、*校准*、*更新*…），或打开能解决它的标签页。条目所说的问题解决后，条目会自动消失。
- **Ⓧ** 把一条仅供参考的条目标记为已读；**Ⓨ** 把它们全部标记为已读。已标记为已读的条目，下次启动时仍为已读，直到它的文字发生变化。
- **忽略：** 少数待处理的条目可以用 Ⓧ 忽略，需要确认并输入 PIN：任何人都会先试的 PIN、PlayGuard 打开时不需要 PIN、“时间到”提醒已关闭、SD 卡空间快满（没有 PIN、家长控制已解除、时钟、主机没有计时，以及 PlayGuard 自己的文件，这些都不能忽略）。已忽略的条目不再计数，列在最后的 *已忽略* 下，在那里按 Ⓐ 会重新计入。它会在 30 天后自动回来（除非关闭了 *30 天后重新计入已忽略的警告*），或者在问题解决后再次出现时回来；对于 PIN，换成另一种长度的新 PIN 时也会回来。
- *偏好设置 › 通知* 可以关闭三类通知：Atmosphère、hekate 和系统版本的新版本；本周的游戏时间；提醒（备份、另一个系统、所有游戏已被阻止）。
- 这些状态在 PlayGuard 启动时读取，在主画面上每分钟读取一次，显示 *今天* 时每 5 秒读取一次。

## 今天——一天的情况一目了然

*[在模拟器中试试 ›](https://playguard.link/simulator/)*

### 圆环和时间线

**剩余时间**以圆环显示：不能玩的日子显示 *不可游玩*，而不是 *0分钟*；今天给的加时在圆环末端显示为颜色较浅的一段，数值变化时圆环会滑动到新的值。

下方是最先让游戏停止的事情：

- 在时间到或就寝提醒之前，一天中剩下的时间显示为一条线，“现在”在最左边，时间到和就寝提醒各是线上一个带时间的标记（*16:40 时间到*、*21:00 就寝*），到第一个标记之前为青绿色，最后 15 分钟内为琥珀色；
- 否则用文字说明：当天的时间用完后，显示就寝提醒，即何时可以再次游玩；家长控制解除期间，显示今天的限制已暂停及原因。

### 各项操作

- **加时**，各个时长按一下就能选：选中某个时长时，线上“时间到”的标记会随之后移（*再加 15分钟*），或在就寝提醒的标记上说明它仍然先到；剩余 15 分钟或更少、或已没有剩余时间时，第一个时长会以青绿色突出显示。
- **今天到此为止**、**给孩子看**。
- **今天的限制…**：当场选择今天的限制，确认一次后写入。
- **正在生效的配置**，保存了配置后按名称显示（没有匹配的配置时显示 *配置…*）：按 Ⓐ 列出所有配置，正在生效的已打勾，确认一次后即可改用另一个（确认时会列出变化的日子），或选择 *管理配置…*。
- 家长控制解除期间，**重新启用** 排在最前面，占满整行，*加时* 则让开。
- 没有任何一天设置了限制时，**设置每周限制** 会打开 *游戏时间* 中的一周。

### 卡片和胶囊标签

- **就寝提醒**（何时可以再次游玩；主机没有提供这个信息时，显示还有多久响起；关闭时以大字显示 *已关闭*，并可按 Ⓐ *设置*）、**家长控制**和**网络时钟**，以卡片显示。
- 主机的状态以**胶囊标签**显示：
  - 其中一个说明 Atmosphère 的 DNS 重定向是否拦截了任天堂的服务器，在它上面按 Ⓐ 会说明拦截了哪些以及会带来什么影响：手机应用无法同步，网络时钟无法自行校准；
  - 另一个在 PlayGuard 是在游戏之上打开时出现，说明在 PlayGuard 中度过的时间也会计入，按 Ⓐ 说明是怎样计入的；
  - 在 HOME 菜单中留着没关的游戏会显示为琥珀色的胶囊标签（*仍在计时*，按 Ⓐ 说明原因），前提是关于在游戏之上打开 PlayGuard 的那个标签还没有说明这一点。
- 胶囊标签先列出需要家长处理的（琥珀色，带三角形），然后是已开启的（青绿色，带勾号），最后是其他的（灰色，带圆点）：形状和颜色一样能表达含义。
- 胶囊标签下方显示仍需恢复的加时（按 Ⓐ 恢复），以及关闭时的“时间到”提醒（按 Ⓐ 重新打开）。

### 入门

在设置 PIN 和每周的限制之前，卡片上方会有一张卡片列出三个步骤（PIN、每日限制、网络时钟），完成的以青绿色打勾，未完成的以琥珀色圈出，并显示完成了几步（*1 / 3*）；在某一步上按 Ⓐ 会直接在那里完成它。

### 主机在计时吗？

PlayGuard 作为应用运行时，它自己的时间也会计入，所以今天有限制时，打开 PlayGuard 期间剩余时间应该减少。如果画面上的剩余时间约 90 秒没有变化（计时器开启、今天有限制、未解除、不是从相册打开），已玩时间下方的一行琥珀色文字会显示 *主机目前没有计算游戏时间*，并列出可能的原因：

- 时钟被调回（之后会重新计时）；
- 网络时钟从未设置（*主机 › 网络时钟*）；
- 刚刚写入了限制（启动一个游戏玩一分钟后再查看）。

剩余时间一有变化，这行文字就会消失。游戏时间标签页也会显示这一点。

### 在 PlayGuard 之外的更改

今天的游戏时间在同一天内重新开始计算（更改时钟会造成这种情况）、主机时钟变动超过 5 分钟、限制与 PlayGuard 上次看到的不同（手机应用、其他工具）：圆环上方会显示一张琥珀色卡片，直到被关闭（Ⓐ）或到第二天，并在更改历史中记录一条。PlayGuard 不在后台运行：它重新读取主机时，只能看到它打开期间或上次打开以来发生的更改。

### 达到限制时

主机显示“时间到”，然后中断游戏（没有“继续”）或只作提醒：设置了限制或就寝时间后，*时间到时* 会显示是哪一种，并可以更改（[详情，英文](../parental-controls.md#when-the-time-runs-out)）。

### 加时和今天停止游玩

- **今天加时**：默认为 +15 分钟、+30 分钟、+1 小时。
- **今天停止游玩**：仅今天把限制设为 0，已知游玩时间时可选 *现在* 或 *5分钟后*（限制会变成已玩时间 + 5 分钟，留出存档的时间）。重新锁定时主机会显示“时间到”，未保存的进度可能丢失——确认时会说明。
- **第二天**——启动时，或者应用开着时在午夜——PlayGuard 会恢复平时的限制：
  - 加时之后，它会自动恢复，不询问也不需要 PIN（它只会降低限制，和重新启用家长控制一样），如果计时器正在计时，会暂时解除一下并立即重新锁定。无法写入时（只读模式、不支持的系统版本、已阻止所有游戏）它会等待；一周后的同一天，如果较低的限制会让正在进行的游戏停止，它也会等待（改到第二天）。想让某一天保留更多时间，请更改那一天的限制；
  - *今天停止游玩* 之后，它会询问是保持 0 还是恢复限制（需要 PIN，和任何提高限制的更改一样），或者像其他更改一样自动恢复（*游戏时间 › “今天停止游玩”后，第二天自动恢复平时的限制*）；需要恢复为“无限制”时总会询问。
- **其他日子加时**（*加时 › 其他日子…*，在列表末尾）：明天或之后五天中的一天，每一天都列出它的限制，然后选择时长。那一天的限制会立即提高，仅限那个日期，那天过后下次打开 PlayGuard 时会自动恢复（它只会降低限制）——没有打开 PlayGuard 的主机不会恢复，下周的同一天也会保留这个限制。一次只能有一个：之后列表会提供取消它的选项（限制立即恢复）。在此期间如果那一天的限制被更改了（每周设置、配置…），以更改为准：不会恢复任何东西。

### 儿童画面

*今天* 中的 *给孩子看*，方便把主机交给孩子：

- 只显示剩余时间（家长控制解除期间，显示今天的限制，已暂停）、游戏何时结束（*约 16:40 结束*；就寝提醒先到时，圆环改为倒数到就寝时间，*距离就寝时间 45 分钟*，与没有限制的日子的最后一小时一样）、就寝时间，以及时间到时会发生什么；
- 文字大小适合在房间另一头看电视时阅读；不受文字大小设置的影响；
- 最后 5 分钟内（游戏结束前或就寝时间前），结束时间变为琥珀色，圆环缓慢跳动；就寝时间在最后 30 分钟内变为琥珀色；
- 家长用的 Ⓐ 和 Ⓨ 以小字显示在右上角，因此底栏只显示孩子用的按键；
- 按 Ⓐ 输入 PIN 后返回家长的画面；按 Ⓨ 输入 PIN 后可以直接在这里加时（时长与 *加时* 相同，之后仍停留在儿童画面）；按 Ⓑ 退出 PlayGuard（和退出时一样，会先询问是否重新启用家长控制）。

文字放大时，*今天* 仍然能在一个画面中完整显示：标题上方的那一行只显示星期和当天的限制（*星期四 · 2小时*），按钮和卡片会稍微紧凑一些。每 5 秒刷新一次（按 Ⓧ 立即刷新）。

## 游戏时间——一周就是编辑器

*[在模拟器中试试 ›](https://playguard.link/simulator/?tab=play_timer)*

### 修改一周

在某一天上按 Ⓐ 开始修改：

| 按钮 | 修改时 |
|---|---|
| ↑/↓ | 以 15 分钟为单位调整（按住时以 1 小时为单位） |
| ←/→ | 切换到下一天 |
| Ⓛ | 复制到星期一至星期五 |
| Ⓡ | 复制到周末 |
| Ⓨ | 无限制 |
| Ⓧ | 精确时长（*输入时长…*：↑/↓ 以 15 分钟（按住时以 1 小时）、Ⓛ/Ⓡ 以 5 分钟为单位，焦点在 OK 上） |
| Ⓐ 或 Ⓑ | 结束修改 |

- 用触摸操作时，点击某一天即可修改，然后点击它的上部或下部，以 15 分钟为单位调整。
- 更改会一起保存，按 **+** 或 *保存*，和按天编辑器一样（确认时会列出更改的日子，更改前 → 更改后）；*放弃* 会还原这些更改。
- 每一天的柱条内显示它最近一次的游玩时间（包括今天，所有用户合计），达到限制后连同限制一起显示为珊瑚色，一周下方的图例会说明（*超出限制*）。
- 已更改但尚未保存的日子，限制显示为琥珀色，柱条带琥珀色边框；一周下方显示选中那一天的数据（*星期四：已玩 1小时20分 / 2小时*）。
- 一周上方以琥珀色显示已达到的限制以及主机此时会怎么做，或者主机没有计算游戏时间。
- `0` 分钟表示 *当天不能玩*；*取消游戏时间限制* 会关闭计时器。

### 标签按钮和快捷设置

一周上方和下方的**标签按钮**会直接打开各自的选项：配置（显示已保存了几个）、每天相同的限制、就寝提醒、*时间到时* 以及取消限制。

- **每天相同的限制**：快捷列表或精确时长（*输入时长…*：↑/↓ 以 15 分钟为单位（按住时以 1 小时为单位），Ⓛ/Ⓡ 以 5 分钟为单位）。
- **工作日和周末 ›**：编辑器，先询问星期一至星期五，再询问周末。
- **今天加时**和**今天停止游玩**，与 *今天* 中相同。它们下方的说明告诉你主机在达到限制时会怎么做。家长控制暂时解除期间，游戏时间 *可能* 不会计入：这一点仍未确定（[文档，英文](../parental-controls.md#still-open)）。
- 每次确认都会列出变化的日子，更改前 → 更改后。

### 配置

- 保存在 SD 卡上的**配置**：应用（已经生效的配置只会说明这一点）、编辑、重命名或删除；保存当前的限制，或新建一个。
- 名称可以使用任何文字（*École*、*周末*、*Выходные* …）——不含拉丁字母的名称会得到专门的文件名，两个会对应到同一个文件的名称会被发现。
- **计划的配置**（*配置 › 计划的配置*）：在一段时间内使用的配置——假期、旅行——第一天和最后一天从接下来的 60 天中选择。
  - 这段时间开始时，PlayGuard 会询问是否应用它（问题下方会画出它要更改的日子）；结束后，会询问是恢复被它替换的限制，还是保留现在的限制。
  - 每天询问一次，在主画面上、前面没有其他内容时询问：PlayGuard 只在打开时才会执行，所以没有打开 PlayGuard 的主机会保持现有的限制。如果这段时间过去了，配置却从未被应用，它就会被忘掉。
  - 一次只能有一个；这一行可以更改、删除或提前结束它。

### 就寝提醒

- 提醒时间（16:00 到 23:45，或关闭）和恢复允许游玩的时间（05:00 到 09:00），每天相同。
- 或者从提醒列表末尾的 *按星期设置…*，分别设置星期一至星期五、周末或某一天，其他日子保持原样（每组日子都和它的时间一起列出）。各天不同时，标签页显示 *每天不同*，*游戏时间* 中的一周会在每一天的名称下方显示它的提醒时间。
- 它在游戏时间设置中的位置是根据手机应用的设置推算出来的，已在主机上验证（22.0.0）；PlayGuard 仍然只在主机报告的值与它读到的一致时才更改它，更改后检查主机的回应，如果不一致就恢复之前的设置。

### 加时设置和高级

- **加时**：提供的时长（+15/+30/+1 小时、+10/+20/+30 分钟…），以及 *今天停止游玩* 之后不询问就恢复平时的限制（加时之后总是不询问就恢复）。两者都在下次打开 PlayGuard 时执行，从第二天开始：没有打开 PlayGuard 的主机会保持那一天的限制。
- **高级 ›**，一个单独的画面：调试类操作的开关，开启后可以打开或关闭“时间到”提醒，以及暂停 / 恢复倒计时。同一个开关也允许备份或历史记录恢复这个提醒。

## 游玩记录——谁玩了什么，玩了多久

*[在模拟器中试试 ›](https://playguard.link/simulator/?tab=activity)*

每个游戏在**今天**、**最近7天**和**累计**的时间，来自主机自身的游玩记录——可以看所有用户，也可以只看**一个用户**（主机有多个用户时，用户以标签按钮显示在顶部）。PlayGuard 启动时显示上次查看的用户，或 *默认账户* 中设置的那个（所有用户，或其中一个）。

### 顶部

- 用户的标签按钮、时间范围和导出。
- 以数字显示今天、最近 7 天和累计的时间。最近 7 天下方按天与前 7 天比较：多了以琥珀色显示，如 ▲ *比上周每天 +20分钟*，少了以 ▼ 和青绿色显示，相差不到 5 分钟时显示 *与上周相当*。
- 以卡片显示玩得最多的四个游戏（按 Ⓐ 打开其中一个）；在最近 7 天中，比前一周增加最多的那个游戏会显示增加了多少，从半小时起显示（▲ *+2小时*）。
- 期间内没有玩过任何游戏时，会有一张卡片说明，有内容可看时还会显示 *查看累计*。

### 图表和摘要

- **最近七天的图表**（今天在右边，下方有图例），本周每天的限制显示为一条线，超出部分以琥珀色显示并标有 !；还有今天、本周和累计的总时间。
- 所选期间（今天、最近 7 天、**最近30天**或累计）内当前用户的**摘要**：每天平均时间、玩得最多的游戏、玩过的天数和玩得最多的一天（最近 7 天）、平均每次时长（累计）。
- **游玩时段（最近7天）**：每天每小时一格，星期一在最前，颜色越深，玩得越多（所有游戏，当前显示的用户）；然后是游玩次数（中间休息不到 5 分钟的游玩算作一次，换了游戏也算）和平均时长、最长的一次及其日期、连续两小时中玩得最多的时段，以及 21:00 至 06:00 之间的游玩时间。

### 所有游戏和单个游戏的页面

- **所有游戏**，一个单独的画面：期间内玩过的所有游戏，玩得最多的排在前面，显示为**图标网格**或**列表**（Ⓨ 切换，选择会被记住），所选游戏的数据始终显示在顶部：图标和名称、期间内的游戏时间、累计时间、启动次数和最后游玩时间。Ⓧ 选择期间（游玩记录标签页随之改变）。
- 图标在所选游戏附近读取（小程序模式下不读取，以节省内存）；图标加载出来之前，以及没有图标的游戏，显示一个灰色手柄。
- 游戏很多时先显示前 50 个，然后是 *显示所有游戏*（小程序模式下最多 100 个）；导出总是包含全部游戏。PlayGuard 最多读取 256 个游戏（优先本周的）：超出时，游玩记录标签页、所有游戏和导出（CSV 除外）会说明有些游戏缺失，累计总时间也不包含它们。
- **在游戏上按 Ⓐ：** 最近七天的柱状图、启动次数、首次和最后游玩时间、每个用户的时间。已删除的游戏保留累计数据，即使是在安装 PlayGuard 之前删除的，只要主机的游玩记录里还有它的名字；PlayGuard 见过它的名称后也会保留名称（否则显示 *已删除的游戏* 和它的 title ID）。

### 用户

- 某个游戏中不属于任何用户的时间（有些游戏从不要求选择用户，或者用户之后被删除了）显示为 *无用户*，从一分钟起显示。
- PlayGuard 以前没见过的用户会在标签页上以琥珀色标出 30 天（*新用户（自…起）*，新建用户是重新开始计时的一种已知方法），并记录在更改历史中；PlayGuard 第一次列出用户时已经存在的那些不会被标出。

### 导出和分享

- **导出到 SD 卡**（*导出* 标签按钮），格式为 CSV、JSON、XLSX（Excel）或 PDF，每天一列，然后是最近 7 天、最近 30 天和累计。
- **以二维码显示本周摘要**：手机相机扫描后会读到几行文字，使用当前显示的语言——最近 7 天及其平均值、趋势、每一天、玩得最多的三个游戏、游玩次数、最长的一次，以及 21:00 至 06:00 之间的游玩时间。不会上传任何内容。
- 打开时立即显示上次读取的数据（在两次运行之间保存在 SD 卡上），超过一分钟会在后台刷新；Ⓧ 立即重新读取，并显示加载图标。
- 如果更改过主机时钟，时间只是近似值。

## PIN——PIN、解除、阻止游戏、手机应用

*[在模拟器中试试 ›](https://playguard.link/simulator/?tab=security)*

- **顶部**有三个方块：PIN、限制和暂时解除，状态正常时（已设置 PIN、限制已开启、已锁定）各带青绿色勾号，需要处理时带琥珀色警告标志。
- **设置或更改PIN**（系统的 PIN 画面）。
- **显示PIN**：先显示警告并输入 PIN 本身，每次都要求；会记录在历史中，然后建议换一个新的 PIN。
- **暂时解除**、**重新启用家长控制**，以及在需要解除的更改之后 PlayGuard 是否立即自动重新启用（默认开启）。

### 用PIN保护PlayGuard

在 PlayGuard 本身中使用 PIN：

| 设置 | 效果 |
|---|---|
| *从不* | PlayGuard 中不使用 PIN（主机设置了 PIN 时，铃铛会标出这一点） |
| *更改前*（默认） | 任何人都可以查看，只有家长能更改 |
| *打开PlayGuard时* | 启动时显示锁定画面 |

- 输入一次后，PIN 在 PlayGuard 关闭之前一直有效；*5分钟后再次要求输入PIN*（默认关闭）会在 5 分钟后再次要求，并且当 PlayGuard 离开前台 5 分钟或更久后回来时，重新显示 *打开PlayGuard时* 的锁定画面。
- 检查在服务层进行，任何更改都无法绕过；重新锁定从不需要 PIN。*显示PIN* 每次都要求输入 PIN，无论哪种模式，即使刚刚输入过；`config.json` 缺失或损坏时按 *更改前* 处理。
- 家长控制仍处于解除状态时**退出**，会询问是否重新锁定（*重新启用并退出* 还会关闭 PlayGuard 所依附的游戏，回到 HOME 菜单而不是 hbmenu）；如果是从 HOME 菜单关闭的，PlayGuard 会在下次启动时重新锁定，重启主机也会自动锁定。

### 阻止所有游戏

一个开关，把每天的限制设为 0，启动游戏就需要 PIN——一种轻量的阻止，不涉及年龄分级或交流限制。

- 它阻止的是启动游戏，而不是 HOME 菜单，并且需要 PIN。
- 关闭后会恢复之前的限制。
- 开启期间，*加时* 和 *今天停止游玩* 会被拒绝，用其他方式设置的限制（配置、备份、历史记录…）会取代它。

### 手机应用

- 是否关联了 Nintendo Switch 家长控制应用、它最后一次同步的时间，以及**解除关联**（否则它下次同步会覆盖这里设置的限制：关联期间，PlayGuard 要求确认的每项更改都会提到这一点）。
- 当 Atmosphère 的 DNS 重定向（`atmosphere/hosts`）把任天堂的家长控制服务器指向别处时，手机应用无法同步：PlayGuard 会在这里显示 *同步已被拦截（DNS）*，其他地方都不再提到手机应用（对话框中没有提示，铃铛中没有条目，入门中没有相应步骤，*今天* 上没有胶囊标签，不提供协助解析，解除关联时也不会说明手机应用会覆盖什么）。
- 关联并且能够同步期间，*解除关联前：协助解析两项设置* 会打开数据块比较（见 [CONTRIBUTING.md](../../CONTRIBUTING.md#no-code-needed)，英文）。

### 删除所有家长控制

需要确认两次，无法撤销；会先保存一份设置备份。

## 主机——网络时钟、已安装的游戏、主机运行的系统

*[在模拟器中试试 ›](https://playguard.link/simulator/?tab=console)*

**顶部**以方块显示主机运行的系统（系统版本、Atmosphère，以及 SD 卡上有 hekate 时的 hekate；按 Ⓐ 打开它的版本说明），然后是诊断，再然后是主机的各行信息，兼容性排在最前（PlayGuard 已在此系统版本上验证过时只显示青绿色勾号，否则显示警告和问题所在）。

### 网络时钟

*网络时钟 ›*，一个单独的画面——游戏时间计时器依赖的时钟。从不连接任天堂服务器的主机，这个时钟会一直不准，从而影响游戏时间计时器。

- **主机时钟和网络时钟**、时区、准确度。当 Atmosphère 的 DNS 重定向（`atmosphere/hosts`）把任天堂的时间服务器（`aauth-lp1.ndas.srv.nintendo.net`）指向别处时，主机无法再自行校准网络时钟：这个画面、铃铛中的条目以及 *今天* 中的卡片都会说明这一点，并指向下面的测量。
- **选择一个公共 NTP 服务器**（内置约 50 个，按地区分组，也可以用你自己的）。
- 向 3 台服务器**测量**（取中位数；服务器之间不一致时显示琥珀色警告），然后**设置网络时钟**——测量结果在 2 分钟内有效，并显示倒计时。确认时会说明：更改时钟会让今天的游戏时间重新计算，整个限制又可以用了。
- **启动时检查网络时钟**：偏差超过一分钟时显示提示消息；它从不设置时钟。

#### 没有服务器回应

在没有联网的主机上，结果下方会出现 *将网络时钟设为主机时钟*（测量失败后，*今天* 中的网络时钟卡片上也会出现），需要同样的确认。

- PlayGuard 没有其他东西可以和主机时钟比较：确认时会显示主机的时间，请你先用手机或手表核对；2026 年之前的主机时钟（从未设置过）会被拒绝。
- 如果 *通过互联网同步时钟* 处于关闭状态，主机时钟保持不变，之后再开启这个设置也不会让它跳变；如果它处于开启状态，主机时钟已经跟随网络时钟，所以确认时会提示你关闭它，如果时间不对就手动设置。
- 它只写入时钟，不写入家长控制，所以不需要解除（*用PIN保护PlayGuard* 的 PIN 仍然适用）；和任何时钟更改一样，它会让今天的游戏时间重新计算。
- 尚未在主机上试过。

### 已安装的游戏

*检查已安装的游戏* 会找出 HOME 菜单无法启动或无法显示的游戏——一直在加载的图标、一个“!”、一个虚线框——在游戏图标下方说明问题所在以及该怎么做，并说明有多少个已安装的游戏有问题。

**它能发现的问题：** 名称和图标无法读取、更新背后的游戏本体缺失、已经没有安装任何内容、文件缺失、主机发现的损坏数据、游戏或仅其更新需要更新的系统版本、密钥比系统版本新、缺少许可（ticket）、主机要求一个已被删除的更新、SD 卡无法读取、主机拒绝启动。

**列表按解决方法分节**，每一节都显示数量和该怎么做，同一问题的游戏放在一起（名称相同的两个游戏以版本或 title ID 区分）：

| 分节 | 包含的内容 |
|---|---|
| **可在此修复** | PlayGuard 能修复的 |
| **待检查** | 主机怀疑有问题的数据：检查结果会告诉你是否需要重新安装游戏 |
| **需重新安装** | 文件丢失或无法使用，或数据被发现损坏：先删除，再重新安装 |
| **固件或 SD 卡** | 游戏没问题，问题在主机 |

- **检查数据：** 数据检查的结果会和游戏一起保留，直到安装了另一个版本：损坏的会移到 *需重新安装*，显示为 *已损坏(已检查)*，附上日期和主机的代码；完好的会从列表中移除。*检查这 5 个游戏* 在一个对话框中逐个检查 *待检查* 中的所有游戏（*第 2 个,共 5 个*），然后说明有多少个损坏、完好或无法检查，并可以直接删除损坏的游戏。
- **同时处理多个游戏：** Ⓨ 选择游戏（前面显示勾号），分节上方的 *同时处理多个游戏* 可以选择整个分节；然后对所有选中的游戏执行同一个操作：检查数据，或删除它们（先保存列表，只问一次，只输入一次 PIN）。
- **在 *需重新安装* 下，** 可以保存它们的列表（JSON 和文本，放在导出文件夹中：名称、title ID、版本、问题），也可以在一次询问、一次 PIN 后一并删除：先保存列表，再删除游戏，这样安装工具就不会再把它们当作已安装。
- **操作：** 当某个操作就是解决方法时，它是对话框的第一个按钮；然后是其他操作：重新接受已安装的版本（主机要求一个已删除的更新时）、只删除更新或追加内容、检查数据是否损坏（主机自身的检查，显示进度并可取消），或删除游戏。
- 版本按游戏自己的方式显示（*版本1.4.0*、*更新 #4*）；修复后，会有提示消息说明游戏是否又能运行了。存档数据始终保留；每项更改都记录在更改历史中。
- **检查的时机：** 打开时立即显示上次的检查结果；然后只重新检查条目有变化的游戏（每天检查一次所有游戏，系统版本更新后也会检查，或按 Ⓧ *重新检查*），每个游戏检查完就立即显示。
- 多个游戏同时出问题，通常说明是 SD 卡的问题，或者游戏是从另一个存储（sysMMC / emuMMC）安装的。
- 分节上方的 *显示* 可以把游戏显示为**列表**或**图标**（图标、名称和问题；选择会被记住），和 *所有游戏* 一样。

### 转发器

*转发器 ›* 是 *Homebrew* 下的一个独立画面：把一个 Homebrew 连同图标和名称放到 HOME 菜单上，之后就能像游戏一样从那里启动（一个 NRO 转发器，和 sphaira 制作的一样）。

- **PlayGuard** 一键完成：使用它自己的图标和名称，转发器启动打开 PlayGuard 时所用的 `.nro`。
- **其他Homebrew**：SD 卡 `/switch` 文件夹（及其下一层文件夹）中的任意 `.nro`，会先询问名称（默认是 `.nro` 自己的名称，可以保留或修改）。图标使用 `.nro` 的图标；尺寸不同或是 PNG 时，会转换为 HOME 菜单显示的 256 × 256 JPEG（`.nro` 没有图标时用手柄图标代替），和 sphaira 的做法一样。含空格的路径会加上引号传给 Homebrew。
- **HOME 菜单上的转发器**，各带图标：由 PlayGuard 创建的（Ⓐ：详细信息、重命名、更改发行商、重新安装、删除）和由其他应用创建的（详细信息、删除）。`.nro` 已不在的会注明；在主机的“设置”中删除的会一直留在列表中，直到重新安装或忘记。重新安装会保留程序 ID，所以 HOME 菜单上的条目会被替换，而不会出现两个；其他工具为同一个 `.nro` 创建的转发器也会被替换。
- **图标与语言：** 尺寸不同的图标、PNG，或带 EXIF 数据或采用渐进式编码的 JPEG（HOME 菜单会将其显示为“?”）会转换为普通的 256 × 256 JPEG。转发器的控制数据只声明美式英语，即其唯一图标的语言：因此无论主机设置为哪种语言，图标都会显示。
- **签名补丁：** 主机只有在打了 fs 和 loader 的签名补丁（sys-patch，或 sigpatch 文件）后才能启动转发器：没有的话，画面会在列表上方说明（详情见 *主机 › 游戏补丁*）。`.nro` 留在原处；删除转发器从不会动它。
- **游戏时间：** 从图标启动的 Homebrew 会作为游戏运行：游戏时间会计入，时间到了也会像其他游戏一样被暂停，游玩记录中也会列出它。PlayGuard 仍可随时从 Homebrew 菜单打开。
- 每项更改在 *用PIN保护PlayGuard* 开启时都需要输入 PIN，在只读模式下会被拒绝，并记录在更改历史中。PlayGuard 创建的内容按系统（sysMMC / emuMMC）分别保存在 `forwarders.json` 中。

### 主机的各行信息

- **系统版本、Atmosphère 和 hekate**（SD 卡上有它的 `bootloader/update.bin` 时），每一项都以琥珀色显示上次检查更新时发现的新版本（*22.0.0 · 23.0.1 已发布*，落后不止一个版本时还会显示落后几个版本）；如果最新的系统版本需要先更新 Atmosphère 或 hekate，或者它们尚不支持该系统版本，系统版本那一行会显示警告图标（系统版本的版本说明会说明原因：它们的版本说明写明支持哪些系统版本）。
- **版本说明：** 在每一项上按 Ⓐ 会打开它们：已安装的版本一个标签页，每个较新版本各一个（最多五个），剩下的标签页给较旧的版本（共六个；Ⓛ / Ⓡ 在它们之间切换），打开时显示下一个版本，带有标签（已安装或较新、支持的最新系统版本、安全修复、家长控制有变更）、按原样发布的说明（英文）、*在线查看*（二维码）以及获取时间。Atmosphère 和 hekate 的说明来自它们的 GitHub 发布页，系统版本的来自 switchbrew；它们保存在 SD 卡上供离线阅读，每天重新获取一次（按 Ⓧ 立即获取）。
- **兼容性**，然后是**存储**（emuMMC 或 sysMMC，另一个系统有自己的家长控制时显示信息图标：按 Ⓐ 查看说明）。
- Atmosphère 是否**隐藏序列号**（部分隐藏，按 Ⓐ 才完整显示；在 emuMMC 上，如果没有隐藏，上一行会显示警告图标，按 Ⓐ 查看说明）。
- **游戏补丁**（sys-patch 或 sigpatch 文件；只使用文件时建议使用 sys-patch：显示信息图标，有需要查看的问题时显示警告图标，按 Ⓐ 查看说明）。

## 安全的设计

**安全地写入游戏时间限制**。在计时器倒计时期间覆盖它的设置会让 Atmosphère 不稳定。所以 PlayGuard 会先检查状态；如果计时器正在计时，确认时会说明将暂时解除家长控制——使用已保存的 PIN，**你无需记住它**。按一下之后，它会解除、检查系统确实报告已解除、写入，然后**立即重新锁定**（如果 *更改后自动重新启用* 已关闭，则会提示你这样做）。服务层在写入之前会再检查一次状态，所以任何画面都无法绕过这项保护。

> [!CAUTION]
> 如果限制低于今天已经玩过的时间，家长控制重新锁定后游戏会立即被中断。会出现这种情况时，确认中会说明。

**22.5 不再崩溃**。`pctl:a` 是有特权的家长控制服务，只接受**一个会话**。原版应用的旧版本一直占用它，导致 HOME 菜单的 PIN 输入（或 PIN 小程序）拿不到它，Atmosphère 可能因此崩溃。PlayGuard 每次操作时才打开会话，并立即释放；应用在后台时，定期刷新会暂停。*（问题由 [anbingxi 的分支](https://github.com/anbingxi/NX-Pctl-Manager/tree/diag/fw22-5-readonly) 诊断。）*

**没有任何东西在后台运行**。时间限制、PIN、提醒和中断都是主机自身的功能；PlayGuard 只修改它们的设置。

## 什么算作游戏时间

游戏时间计时器是主机的：PlayGuard 只读取它，自己不计算任何东西。已知的情况，以及确定程度（测量数据见 [parental-controls.md](../parental-controls.md#time-spent-and-time-left)，英文）：

| 情况 | 计入吗？ | 确定程度 |
|---|---|---|
| 正在运行的游戏 | 是 | 已测量（22.0.0） |
| **在 HOME 菜单中留着没关的游戏**（在后台暂停） | **是**：关闭它，或让主机进入睡眠模式 | 家长反馈（[Arqade](https://gaming.stackexchange.com/questions/398954/)）；与测量结果一致（只要有应用开着，主机就会计时） |
| 睡眠模式 | 否 | 有反馈（[Arqade](https://gaming.stackexchange.com/questions/398954/)）；PlayGuard 未测量 |
| **在游戏之上打开的 PlayGuard**（作为应用） | **是**，算作那个游戏的时间 | 已测量（22.0.0）：用家长的用户打开它，或者想快速看一眼时从相册打开 |
| 从相册打开的 PlayGuard（小程序模式） | 否 | 推断：它不是应用，而应用之外的时间似乎不计入 |
| 家长控制暂时解除期间 | 可能不计入 | 未测量：仍未确定 |
| 更改时钟之后 | 当天重新开始计算；时钟往回调后，计时会停止，直到时钟走过原来的时间 | 已观察到（22.0.0）；主机没有计时时，*今天* 会说明 |
