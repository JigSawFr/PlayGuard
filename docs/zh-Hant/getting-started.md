# 開始使用

從 SD 卡到一台為孩子設定好的主機，大約十分鐘，接著是日常的操作。返回 [README](../../README.md)。

## 開始之前

- **一台執行 Atmosphère 的主機。** PlayGuard 透過一個受限的服務操作主機本身的家長監護：它需要自訂韌體。主機沒有改機？那它幫不上忙（[疑難排解](troubleshooting.md#未改機的主機)）。
- **支援的韌體。** 21.0.0 到 23.0.1 可以使用所有功能；更早的版本，除了遊玩時間限制以外都可用；更新的版本會以唯讀方式開啟，直到有版本支援它為止（[相容性](compatibility.md)）。
- **整台主機一個上限。** 遊玩時間限制是主機的：所有使用者都一樣。每個孩子需要不同的上限，就要用其他工具（[原因](compatibility.md#playguard-還是替代型-sysmodule)）。

想先看看？[在瀏覽器中試用 PlayGuard](https://playguard.link/simulator/?not_set_up=1)，對著一台第一次啟動的模擬主機。

## 1. 安裝

從[最新版本](https://github.com/JigSawFr/PlayGuard/releases/latest)下載 `playguard.zip`，解壓縮到 SD 卡的根目錄（[安裝](install.md)）。PlayGuard 還沒有上架 Homebrew App Store 或 sphaira：它的商店頁面仍在等待審核。

> [!TIP]
> 也請解壓縮 `playguard-rescue.zip`，也就是選用的復原 sysmodule。在你需要它之前，它什麼都不做；而當 0 分鐘的上限封鎖了一切、又忘了PIN碼時，它是唯一能重新進入的方法（[被鎖在外面？](troubleshooting.md#被鎖在外面)）。

## 2. 用正確的方式開啟

請**在遊戲之上**開啟 PlayGuard（啟動遊戲時按住 R，透過 hbmenu、sphaira 或 Homebrew App Store），並使用**家長的使用者**：

- 在遊戲之上，PlayGuard 以應用程式的方式執行，可以使用全部的記憶體；從相簿開啟時，它以 applet 的方式執行，記憶體較少；
- 主機會把在 PlayGuard 裡的時間算成那款遊戲的時間，並算在啟動時選擇的使用者身上：要是家長的，不是孩子的；
- 輸入PIN碼後，你在 PlayGuard 中時，它會暫停家長監護，這段時間就不會佔用孩子的時間；你離開時，家長監護會重新開啟。

## 3. 依照*初始設定*操作

第一次啟動時，會出現*初始設定*引導（之後可以在*偏好設定 › 初始設定*中找到）。在完成之前，*今天*會以一張卡片顯示同樣的步驟（*1 / 3*）：

1. **PIN碼。** 主機本身的PIN碼，HOME 選單在超過上限後啟動遊戲或變更設定時會要求輸入。請避免 0000、1234 或 2580：PlayGuard 會標示出任何人都會先試的PIN碼。
2. **每日上限。** 每天相同，或平日一個、週末一個。之後可以在*遊玩時間限制*中變更任何一天。
3. **網路時鐘。** 遊玩時間限制依據它計時。從不連線任天堂伺服器的主機，這個時鐘會一直不準確：請見第 5 步。

## 4. 解除手機應用程式的連動

仍與任天堂的*家長監護*應用程式連動（或是二手主機，連動的是別人的帳號）？*安全 › 解除手機應用程式的連動*。否則手機應用程式下次同步時，會覆蓋你在 PlayGuard 中設定的內容。這個操作可以離線進行。

## 5. 設定網路時鐘

*主機 › 網路時鐘 › 測量時間差*會詢問三個公用時間伺服器，接著選擇*設定網路時鐘*。設定時鐘會讓今天的遊玩時間重新計算，所以請在孩子玩之前進行。

沒有網際網路的主機：沒有伺服器回應時，PlayGuard 會改為提議把網路時鐘設為主機時鐘。請先用手機或手錶核對主機時鐘，同時讓*系統設定 › 主機 › 日期與時間 › 透過網際網路同步時鐘*保持關閉（[詳細說明](features.md#網路時鐘)）。

## 6. 選擇時間到時會發生什麼事

*遊玩時間限制 › 時間到時*：主機會顯示「時間到」，接著**中斷遊戲**或**只提醒**。中斷可以不必爭吵就讓遊戲停下來，但未儲存的進度可能會遺失；只提醒則交給孩子自己決定。如果需要，也可以在同一個分頁加上**就寢鬧鐘**。

## 7. 保護 PlayGuard 本身

*安全 › 用PIN碼保護PlayGuard*：

- **變更前**（預設）——任何人都可以查看，只有家長能變更；
- **開啟PlayGuard時**——啟動時顯示鎖定畫面；
- **永不**——主機設有PIN碼時，PlayGuard 會在鈴鐺中標示這一點。

## 8. 把主機交給孩子

*今天 › 給孩子看*只顯示剩餘時間和遊戲何時結束，字夠大，在房間另一頭也看得清楚。按 Ⓐ 並輸入PIN碼即可回到家長的畫面。

> [!IMPORTANT]
> **留在 HOME 選單上的遊戲會繼續計時。** 請關閉遊戲，或讓主機進入休眠模式（[哪些時間算遊玩時間](features.md#哪些時間算遊玩時間)）。

## 日常操作

| 要… | 在哪裡 |
|---|---|
| 今天多給一點時間 | *今天 › 延長時間*（+15 分鐘、+30 分鐘、+1 小時）。隔天會自動改回。 |
| 其他日子多給一點時間 | *今天 › 延長時間 › 其他日子…* |
| 今天到此為止 | *今天 › 今天到此為止*：現在，或 5 分鐘後，留時間存檔。 |
| 變更某一天的上限 | *遊玩時間限制*：在那一天上按 Ⓐ，↑/↓，然後按 **+** 儲存。 |
| 在上學期間和假期之間切換 | *遊玩時間限制 › 設定檔*；*排定的設定檔*用於事先選定的一段期間。 |
| 看看誰玩了什麼 | *活動紀錄*：依遊戲、依帳號，今天、7 天、全部期間；可匯出或以 QR 碼顯示。 |
| 暫時封鎖所有遊戲 | *遊玩時間限制 › 封鎖所有遊戲*。關閉後會恢復先前的上限。 |
| 復原一項變更 | 變更後立即按 **ZR** *復原*，或隨時到*紀錄 › 使用PlayGuard進行的變更*。 |
| 保留一份設定 | *紀錄 › 備份設定*（絕不包含PIN碼）。 |
| 知道哪些事需要你處理 | 鈴鐺（Ⓨ）：需要處理的以琥珀色顯示，需要知道的附「i」。 |
