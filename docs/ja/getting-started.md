# はじめに

SD カードから、子どものために設定した本体まで、約 10 分で進めます。そのあとは、ふだんの操作です。トップページは [README](../../README.md)。

## 始める前に

- **Atmosphère で動く本体。** PlayGuard は、制限されたサービスを通じて本体自身のみまもり設定を操作します。そのため、カスタムファームウェアが必要です。改造していない本体では使えません（[トラブルシューティング](troubleshooting.md#改造していない本体)）。
- **対応するファームウェア。** 21.0.0～23.0.1 ならすべての機能が使えます。それより前は、プレイ時間の制限以外すべてが使えます。それより新しい場合は、対応するリリースが出るまで閲覧のみで開きます（[対応状況](compatibility.md)）。
- **本体全体でひとつの上限。** タイマーは本体のもので、すべてのユーザーに共通です。子どもごとに別の上限が必要なら、別のツールが必要です（[理由](compatibility.md#playguard-か置き換え型の-sysmodule-か)）。

先にようすを見てみたいですか？ [ブラウザーで PlayGuard を試す](https://guard.boreale.dev/simulator/?not_set_up=1)と、初めて起動したときの本体をシミュレーションで操作できます。

## 1. インストールする

Homebrew App Store か sphaira の App Store で *PlayGuard* を検索してインストールします。手動の場合は、[最新リリース](https://github.com/JigSawFr/PlayGuard/releases/latest)の `playguard.zip` を SD カードのルートに展開します（[インストール](install.md)）。

> [!TIP]
> オプションのリカバリー sysmodule、`playguard-rescue.zip` も展開しておいてください。必要になるまで何もしません。上限 0 分ですべてがブロックされ、暗証番号も忘れたときに、本体に戻れる唯一の方法です（[ロックされて入れない？](troubleshooting.md#ロックされて入れない)）。

## 2. 正しい方法で開く

PlayGuard は **ゲームの上から**（hbmenu、sphaira、Homebrew App Store で、R を押しながらゲームを起動）、**保護者のユーザー** で開きます。

- ゲームの上からなら、PlayGuard はアプリケーションとして動き、メモリーをすべて使えます。アルバムからだとアプレットとして動き、使えるメモリーが少なくなります。
- その時間は子どものプレイ時間として数えられます。ただし *セキュリティ › PlayGuardを使っている間、みまもり設定を一時停止する* がオン（初期設定はオフ）なら、暗証番号を入力したあとは PlayGuard を使っている間みまもり設定が一時停止し、PlayGuard から離れるとまた有効になります。
- 暗証番号を入力すると、PlayGuard を使っている間はみまもり設定が一時停止するので、その時間は子どものプレイ時間から引かれません。PlayGuard から離れると、また有効になります。

## 3. *はじめに* に従う

初めて起動すると、*はじめに* のガイドが表示されます（あとからは *オプション › はじめに*）。*今日* にも、終わるまで同じステップがカードで表示されます（*1 / 3*）。

1. **暗証番号。** 本体自身の暗証番号で、上限を超えてゲームを始めるときや設定を変えるときに、HOME メニューが求めます。0000、1234、2580 は避けてください。誰もが最初に試す暗証番号は、PlayGuard が知らせます。
2. **1 日の上限。** 毎日同じにするか、平日と週末で分けます。1 日ごとの上限は、あとで *プレイ時間* で変更できます。
3. **ネットワーク時計。** タイマーはこの時計で数えます。任天堂のサーバーにつながらない本体では、不正確なままになります。ステップ 5 を参照してください。

## 4. スマホアプリとの連携を解除する

任天堂の *Nintendo みまもり Switch* アプリとまだ連携していますか（または、中古の本体がほかの人のアプリと連携している）？ *セキュリティ › スマホアプリとの連携を解除* を選んでください。解除しないと、アプリの次の同期で、PlayGuard で設定した内容が上書きされます。オフラインでも使えます。

## 5. ネットワーク時計を合わせる

*本体 › ネットワーク時計 › 時刻のずれを測定* で 3 つの公開時刻サーバーに問い合わせ、*ネットワーク時計を合わせる* を選びます。時計を合わせると今日のプレイ時間がリセットされるので、子どもが遊ぶ前にしてください。

インターネットのない本体では、どのサーバーも応答しないとき、代わりにネットワーク時計を本体の時計に合わせることを PlayGuard が提案します。先に、*設定 › 本体 › 日付と時刻 › インターネットで時計を合わせる* をオフにしたまま、本体の時計をスマートフォンや時計で確かめてください（[詳細](features.md#ネットワーク時計)）。

## 6. 時間になったときの動作を選ぶ

*プレイ時間 › 時間になったとき*：本体は「時間です」と表示し、そのあと **ゲームを中断する** か、**知らせるだけ** です。中断すれば、もめることなくプレイが止まりますが、セーブしていない進行状況は失われることがあります。知らせるだけなら、子どもに任せることになります。必要なら、同じタブで **おやすみアラーム** も設定できます。

## 7. PlayGuard 自体を守る

*セキュリティ › PlayGuardを暗証番号で保護*：

- **変更する前**（初期設定） — 誰でも見られ、変更は保護者だけ。
- **PlayGuardを開くとき** — 起動時にロック画面。
- **しない** — 暗証番号が設定されている間は、PlayGuard がベルでそれを知らせます。

## 8. 本体を子どもに渡す

*今日 › 子どもに見せる* は、残り時間とプレイが終わる時刻だけを、部屋の反対側からでも読める大きさで表示します。Ⓐ と暗証番号で、保護者の画面に戻ります。

> [!IMPORTANT]
> **HOME メニューで開いたままのゲームは、カウントされ続けます。** ゲームを終了するか、本体をスリープモードにしてください（[数えられるもの](features.md#プレイ時間として数えられるもの)）。

## ふだんの操作

| したいこと | 場所 |
|---|---|
| 今日の時間を延長する | *今日 › 時間を延長*（+15 分、+30 分、+1 時間）。翌日、自動で元に戻ります。 |
| 別の日の時間を延長する | *今日 › 時間を延長 › 別の日…* |
| 今日はもう終わりにする | *今日 › 今日は終了*：今すぐ、またはセーブできるように 5 分後。 |
| 1 日の上限を変える | *プレイ時間*：曜日で Ⓐ、↑/↓、**+** で保存。 |
| 学校のある時期と休みを切り替える | *プレイ時間 › プリセット*。 |
| 誰が何を遊んだかを見る | *プレイ記録*：ゲームごと、ユーザーごと、今日、7 日間、これまでの合計。エクスポートも。 |
| 今すぐすべてのゲームをブロックする | *プレイ時間 › すべてのソフトをブロック*。オフにすると、前の上限に戻ります。 |
| 変更を元に戻す | 直後なら **ZR** *元に戻す*、いつでも *履歴 › PlayGuardで行った変更*。 |
| 設定のコピーを残す | *履歴 › 設定をバックアップ*（暗証番号は含みません）。 |
| 対応が必要なことを知る | ベル（Ⓨ）：対応が必要なことはオレンジ、知っておくことは「i」で表示。 |
